# madamecalista.com

The public site for **Madame Calista: Tarot Reading**: a landing page, the support page and the privacy policy. Static HTML on GitHub Pages, following the plonkthegame-site pattern.

- `index.html`: landing page (swap the "On the App Store October 27" pill for the App Store badge and link on launch day)
- `support.html`, `privacy.html`: updated copies of the nexus-app-pages Calista pages (the App Store build still links the nexus-app-pages URLs, which stay live)
- `CNAME`: custom domain for GitHub Pages
- `assets/`: stylesheet, portrait, icons, social preview image

Contact is still the GitHub issue form; switch to support@madamecalista.com once the address exists.
